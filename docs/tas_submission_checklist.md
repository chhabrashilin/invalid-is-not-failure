## Known gap (disclosed, must be closed for camera-ready)

No LaTeX toolchain is installed on the machine used to prepare this submission,
and installing one was not feasible before the deadline. Consequences:

- `paper/main.tex` is written for the AAAI 2026 author kit (`aaai26.sty`,
  `\bibliographystyle{aaai26}`) but **has not been compiled**. It may need
  trivial fixes (e.g. the AAAI kit's `\nocopyright` / metadata requirements) on
  first build.
- `paper/main.pdf` was produced by rendering `paper/main.html` with headless
  Chrome to US Letter. The layout closely follows AAAI conventions — two
  columns, ~9.5pt serif body, centred title block, full-width table — but it is
  **not** the official AAAI class output, so column widths and margins are
  approximate rather than exact.

**Action for camera-ready:** install TeX Live, drop the AAAI 2026 author kit
into `paper/`, run `pdflatex; bibtex; pdflatex; pdflatex`, and replace
`main.pdf` with the class-produced output. Content is identical between
`main.tex` and `main.html`.

## Anonymity audit performed

Searched `paper/main.tex`, `paper/main.html`, `paper/references.bib`, and the
`paper/main.pdf` binary for: author surname, given name, university/affiliation
strings, `.edu` addresses, GitHub usernames, `github.com` URLs, Windows user
paths (`C:\Users\...`), the project directory name, and acknowledgements.
**Result: no matches in any file.** PDF metadata contains only `/Title`,
`/Creator` (browser UA string), and `/Producer` (`Skia/PDF`) — no `/Author`.
