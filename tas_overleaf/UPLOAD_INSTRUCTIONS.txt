   Put aaai2026.sty and aaai2026.bst in the project root.

3. Upload from tas_overleaf/ into the same project root:

      references.bib

4. Menu -> Compiler: pdfLaTeX.  Menu -> Main document: main.tex.
   Recompile. Overleaf runs bibtex automatically; if references show as [?],
   press Recompile once more.

5. Download PDF and submit to EasyChair.

ANONYMITY
---------
main.tex uses  \usepackage[submission]{aaai2026}  which suppresses the author
block and the copyright notice, plus \author{Anonymous Submission} and an empty
\affiliations{} -- exactly what the AAAI kit specifies for anonymous review.
Verified: no author name, affiliation, email, username, path, institution, or
repository URL appears in the source or in the compiled PDF. PDF metadata
carries no /Author field.
